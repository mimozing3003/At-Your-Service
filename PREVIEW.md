## 🎯 HOW TO USE - STEP BY STEP

### Step 1: Open Application
```
http://localhost:5173
```

### Step 2: Create Account (Optional but recommended)
1. Click "Sign Up" button (top right)
2. Fill in: Name, Email, Password
3. Click "Register"
4. You'll be automatically logged in

### Step 3: Try AI-Powered Search

**Search Examples to Try:**

```
teacher in Kolkata ₹600/hr
```
→ Will find math and science tutors with hourly rates

```
beauty salon in Asansol under 500
```
→ Will find Glam Studio Salon

```
yoga instructor in Siliguri
```
→ Will find Zen Yoga & Wellness

```
plumber in Habra under 500
```
→ Will find top-rated plumbers in your price range

```
electrician in Durgapur
```
→ Will show Quick Fix Electricals

### Step 4: See AI Magic ✨
After searching, you'll see:
- **AI Understanding:** Parsed service type, price, location
- **Smart Scoring:** Each result has a score based on rating, price, distance, sentiment
- **Why This?:** Explanation for why each service is recommended
- **Review Summary:** AI-generated summary of all reviews

### Step 5: Book a Service
1. Click on any service card
2. View details, reviews, location on map
3. Click "Book Now" button
4. Select date and add notes
5. Confirm booking
6. View booking in "My Bookings"

### Step 6: Try Dark Mode 🌙
1. Look for sun/moon icon in navbar
2. Click to toggle dark mode
3. Enjoy the dark theme!
